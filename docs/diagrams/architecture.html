2核心：LangGraph 流水线按 task_type 分叉

每次请求前端注入 [task:TYPE],后端路由最少阶段,评估不过再循环

task_type → 阶段链 最少路径
  • continue：retrieval → draft → safety
  • rewrite / polish：refine → safety
  • outline：retrieval → draft → safety
  • generate：完整 5 阶段 + 循环
RAG 检索 smart_setting_priority
  • 4 集合：章节/角色/世界观/剧情事件
  • pgvector 语义检索，小说设定优先
  • 结果注入 draft/refine 提示词
  • 检索失败降级为无上下文（不阻断）
评估矩阵 fallback
  • 多维度评分，单维度 30s 超时
  • 失败返回 0.5 分 fallback
  • 低于阈值最多重试 5 次
  • 评估结果持久化
内容安全 内置规则
  • stage 级 pre-check
  • 交稿雷达：隐私/版权/敏感预检
  • 规则集在 app/safety/

3安全边界：BYOK 凭证与入站校验

入站（客户端 → 后端）
  • 受保护端点需 X-API-Key（白名单 API_KEYS）
  • 未配置时 503 + 引导文案
  • 文档 ownership 校验（跨租户 404）
出站（后端 → LLM）
  • BYOK 凭证经 X-Provider-Config 上传
  • api_base SSRF 校验（APIBaseNotAllowed）
  • 日志日志脱敏（_redact_key）
