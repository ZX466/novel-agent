编排层 — 三阶段流水线（LangGraph）

一次 AI 生成在流水线里流经的五个部件。按任务类型短路：续写只走 检索→初稿→安全，生成正文走全链，重写/降AI 跳过检索。

流水线节点
🔎检索记忆 Agentretrieval

按当前文本+大纲语义检索五源记忆，拼装写作上下文

输入 章节文本·outline → 输出 writing_context

协作 记忆层五源 · 失败降级为无上下文（不阻断）

✍️初稿 Agentdraft

按章节进度/人物树/字数目标生成正文；流式吐 token；字数后检（<0.6 重写 / 0.6-0.9 续写）

输入 writing_context → 输出 draft 流

协作 BYOK 草稿阶段模型 · thinking 流过滤

🪄精修 Agentrefine

对初稿做文笔打磨，最多迭代 5 轮（防震荡硬上限）

输入 draft → 输出 refined

协作 BYOK 精修阶段模型

⚖️评审 Agentevaluate

六维并行评审（连贯/人设/文笔/逻辑/世界观/跨章）；分数低于阈值回炉精修

输入 refined → 输出 score·反馈

协作 精修 Agent（不合格回流）· 单维 30s 超时→0.5 兜底

🛡安全检查 Agentsafety_check

流水线内安全过审；失败转降级模式继续（可见性优先）

输入 refined → 输出 安全结果

协作 交稿雷达 Agent（同引擎不同入口）

记忆层 — RAG 五源 + 嵌入

AI「记得什么」的全部来源。写路径不等待嵌入（后台任务），「索引中」徽标消散后新内容才进检索。

记忆源
📖章节记忆chapters

正文按章入库；保存即快照可回溯；AI 段落带标记，标记索引持久化在 metadata

输入 编辑器保存 → 输出 ch1..n 向量

协作 嵌入 Agent（后台）

👤人物 + 关系characters · relationships

人物卡（角色/弧线/属性）与关系边（类型/强度）各自成源；关系树序列化进提示词

输入 面板 CRUD·大纲提取 → 输出 人物向量·关系树

协作 嵌入 Agent · 大纲提取 Agent

🌍世界观记忆world_settings

力量体系/地理/势力等设定条目，按分类管理

输入 面板 CRUD·灵感套件 → 输出 设定向量

协作 嵌入 Agent

📋剧情事件 + 因果链plot_events · timeline

事件带前驱（prev_event_id）成 DAG；章节保存时实时校验因果冲突（顺序倒置/前驱缺失）

输入 面板 CRUD → 输出 事件向量·warnings

协作 时间线 DAG Agent · 时间线可视化

📚知识文档knowledge_docs

外部资料 txt/md 上传（或粘贴），服务端分块嵌入——喂给 AI 的「设定资料库」

输入 记忆库上传 → 输出 分块向量

协作 嵌入 Agent · 限流/大小/二进制防御

🧬嵌入 Agentbackground_embed

四类写路径共用的后台索引器：独立会话+脱离任务，写响应绝不等它；成功后清「索引中」标志

输入 任意 lore 写入 → 输出 4096 维向量

协作 BYOK embedding 阶段 · 失败静默降级（RAG 缺席不报错）

守护层 — 质量 · 安全 · 一致性

🛡️交稿雷达/safety

导出前全文安全扫描；有发现先弹报告，作者确认后继续导出

输入 全文 → 输出 findings 报告

协作 导出 Agent（预检钩子）

⚔️一致性哨兵/consistency

按章检查设定冲突，给证据片段；历史检查记录可回看

输入 章节文本+设定 → 输出 冲突清单

协作 记忆层（取证）

🕰时间线 DAG 校验器timeline.validate

写入时即校验因果链：悬空前驱/章节倒置/循环；警告随章节 metadata 持久化

输入 plot_events 全量 → 输出 TimelineWarning[]

协作 剧情事件面板（警示展示）

🚪门卫 Agent_deps

两套 key 分离：BYOK 供应商配置（X-Provider-Config，带 SSRF 校验）与站主 X-API-Key（owner 哈希租户隔离）；跨租户一律 404 防探测

输入 每个请求 → 输出 放行/401/404

协作 Redis 限流（chat 60s 窗口）

创作工具层 — 前端部件

作者直接操作的部件。带 ★ 的把任务路由进流水线（[task:TYPE] 标记）。

📝编辑器核心 ★page.tsx + 8 hooks

TipTap 正文：防抖字数、查找替换、专注模式、快照恢复、自动保存（Ctrl+S 秒回）

输出 content_text + ai_paragraphs

协作 章节记忆 · 版本历史 Agent

🧰AI 工具面板 ★AIToolPanel

六工具：生成正文/续写/扩写/重写/降AI/生成总纲；五阶段进度条实时点亮（SSE wire 级解析）

输入 选区·章节·大纲 → 输出 插入/替换正文

协作 流水线全部 · PerfChatTransport

🎬创作向导 ★CreationWizard

题材→大纲→应用 三步开书：建作品+自动分章+提取人物/设定/事件

输入 三步表单 → 输出 作品+章节+lore

协作 大纲提取 Agent（409 重复自动跳过）

💡灵感套件 ★CreativeKitDialog

一键生成世界观+人物+主线包，预览后原子应用到作品（服务端行锁事务）

输入 题材/基调/关键词 → 输出 kit 应用

协作 世界观/人物记忆

🧙AI 编剧AssistantPanel

对话式创作顾问：带章节/全文上下文，回复可一键插入正文

输入 对话+工作上下文 → 输出 建议文本

协作 检索记忆 Agent（assistant 任务型）

🕸可视化三件套graph 页 · memory 页

关系图（力导向+拖拽+强度编辑）、时间线 DAG（高度自适应）、记忆库（六源统一管理+知识上传）；SVG viewBox 自适应缩放

输入 关系边·事件·六源记忆 → 输出 图上直接改

协作 记忆层全部

🧠大纲提取 Agent ★entity-extraction

从大纲批量抽取人物/设定/事件入库；allSettled 批量容错，409 重复友好跳过

输入 outline 文本 → 输出 lore 三源行

协作 人物/世界观/事件记忆

📦导出 + 快照export · snapshots

MD/TXT/EPUB 三格式导出（自动预快照）；保存/插入/替换前置快照，随时回滚

输入 全书/章节 → 输出 文件·版本点

协作 交稿雷达（导出预检）

附：任务类型 → 流水线路由

前端 [task:TYPE] 标记决定流水线走哪些节点——速度与质量的取舍在路由层完成。

generate 生成全链五节点
continue 续写检索→初稿→安全
rewrite/polish精修→安全
outline 总纲检索→初稿→安全
extract 提取仅初稿（JSON）
assistant 编剧检索→初稿→安全
