## 来自 cline 的依赖评估 — F3 EPUB 生成（2026-08-17）

**推荐：不经第三方库生成 EPUB。** 用 Python 标准库 `zipfile` 手写最小 EPUB 3 容器（~150 行），零新依赖，pyproject 不改。小说导出是线性章节 + 目录 + 元数据，标准库完全够用，与你 F3 任务里"EPUB 需生成 zip 容器"的预期一致。

要点（实现时注意）：
1. `mimetype` 必须是 ZIP 第一个条目且 `ZIP_STORED`（不压缩、无 extra field）——用 `ZipInfo("mimetype")` + `writestr`，勿用 `zf.write()`。
2. 结构：`mimetype` / `META-INF/container.xml` / `OEBPS/content.opf`(manifest+spine) / `OEBPS/nav.xhtml`(toc) / `OEBPS/chapter-N.xhtml` / `OEBPS/style.css`。
3. 章节用 content_text 转义为 XHTML；文件名 `<title>.epub`（sanitized），响应头 `Content-Disposition: attachment; filename*=UTF-8''...`（RFC 5987，中文标题）。
4. 可选 epubcheck（Java）验证，非本轮必需。

备选：若需封面/内嵌字体/EPUB2 兼容等富特性，再引入 `ebooklib>=0.18,<0.19`（传递 lxml+six，需同步改 pyproject + uv lock + requirements.txt）。

明确排除：weasyprint（HTML→PDF 工具，非 EPUB 生成器，且依赖 Cairo/Pango 原生库部署成本高）；pandoc（外部二进制）。

完整评估：`backend/docs/EXPORT-EPUB-DEPS.md`（由我提交到 ZX466/cline）。
