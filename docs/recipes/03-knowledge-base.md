# 卡片 03｜喂知识库

> 目标：上传设定/参考资料，让 AI 在续写时自动检索引用（小说设定优先）。

## 操作步骤

1. **进入知识库**
   - 作品页 → “知识库”入口（受保护端点，需 `X-API-Key`）。

2. **上传资料**
   - 支持白名单类型（文本类）与大小限制；`POST /v1/knowledge_docs`（multipart）。
   - 后端自动分块 + 向量化入库。

3. **确认检索生效**
   - 在知识库列表查看已上传文件（`GET /v1/knowledge_docs`）。
   - 之后续写时，AI 检索会自动合并知识库内容，设定类信息优先命中。

4. **删除（可选）**
   - 不再需要的资料：`DELETE /v1/knowledge_docs/{title}`。

## 一行验证

> 上传一段“人物设定”后提问“主角的性格是什么”，AI 回答与上传内容一致。

## 常见坑

- **上传 401/503**：受保护端点需配置 `API_KEYS` 并携带 `X-API-Key`。
- **二进制文件被拒**：上传接口做二进制探测，只接受文本类资料（`_looks_like_binary`）。
- **检索没命中**：确认资料已分块向量化完成；内容过短或过于零散可能导致召回率低。上传频率受控（`_enforce_upload_rate_limit`），快速连传会 429。
