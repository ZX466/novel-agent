1三栏布局总览

编辑器页(/novels/{id}/editor)分三栏:

  • 左栏(200px):七个标签页——大纲 / 角色 / 世界观 / 剧情 / 关系图 / 时间线 / 🛡一致性,顶部有「✨ 灵感套件」入口;
  • 中栏(自适应):章节标题条、格式工具栏、正文编辑区;右上角悬浮「导出」和显示设置(字号/行高/页宽);
  • 右栏(220px):「AI 工具」和「AI 编剧」两个标签页。
专注模式:按 Ctrl+Shift+F 或 Ctrl+\ 进入——两侧栏与顶栏全部收起,只剩正文和一条极简工具条(标题/保存/退出),再按一次退出。

2开始写作:建作品到进章节

  1. 我的作品页 →「新建作品」,或用「✨ 创作向导」分步引导(标题/简介/体裁)。
  2. 进入作品后点左栏大纲里的某一章才会打开正文——刚进来时正文区是空的(占位符「开始写作…」),这不是 bug。
  3. 没有章节时,点大纲面板的「+」新建,或先生成总纲(见 §3)再「应用大纲」批量建章。

3左侧 · 大纲与章节管理

大纲面板是全书的中枢,顶部一排操作:

按钮作用
AI 提取把当前大纲文本交给 AI,提取角色 / 世界观 / 剧情事件 / 人物关系,写入对应设定面板(角色建完才导入关系线,保证按名字解析到 id)。
AI 润色保持卷/章结构、章节题目、情节走向完全不变,只改进表达。走 rewrite 快速管线。完稿后你确认才会写入。
⤢ 全局弹出居中大窗(92vw×86vh)编辑大纲,超长篇(千行级)必备。Esc 或点遮罩退出。
编辑/保存直接手改大纲。大纲完全归你管——其他任何功能(灵感套件等)都不会写这个字段。

生成总纲

右侧 AI 工具 →「📋 生成总纲」,会先弹出表单:体裁(玄幻/都市/历史…)、风格基调、故事简介、目标章数。目标章数 > 40 时自动切分卷模式:全书按每卷 100-200 章组织,每卷一小段概括 + 卷内只列「第X章 标题」不写内容(千章量级逐章梗概会撑爆输出)。提示词内置标题多样性约束(禁止重复、每 50 章换意象组、禁「X之Y」模板)。

应用大纲 → 章节自动进左栏

生成结果确认后点「📋 应用大纲」:总纲存入作品元数据,同时解析全部章节自动创建到左栏(含拖拽排序的列表视图和脑图视图)。重复标题自动加「·2」后缀消歧;同名章节重复应用不会叠加「·2·2」。

章节操作

  • 列表中拖拽排序、悬停重命名/删除;脑图视图里每章有「直接续写此章节」按钮(跳到该章并打开 AI 工具)。
  • 卷→章结构的大纲在生成正文时,自动携带「本卷脉络」:当前章所在卷的主线概括 + 上一章标题(标注"本章须为其铺垫")+ 下一章标题,让逐章生成知道自己在全书的位置。

4左侧 · 设定面板

五个设定标签页,所有数据都会进入 AI 的检索记忆(见 §12):

  • 角色:姓名/定位/描述/成长弧线。AI 生成时会参考,灵感套件生成的主角若与库内同名会自动降为配角。
  • 世界观:分类(地理/势力/体系/其他)+ 条目。与知识文档同为"小说设定优先"检索源,排序时加分。
  • 剧情:每个事件可指定前驱事件(下拉选择,构成因果链)。客户端会沿前驱链预检成环,成环的候选直接禁用;服务端检测到环只警告不拒绝。
  • 关系图:人物关系可视化。两处入口写入:AI 提取大纲(强度 1-10)、灵感套件(强度 1-5,存储时 ×2)。删除按"谁—对谁"这条边删。
  • 时间线:剧情事件按章节索引排布的时序图,超过 5000 事件截断。
灵感套件(左栏顶部「✨」):一键生成一整套世界观/人物/关系/主线。生成前自动注入作品现状(标题/简介/角色/世界观/大纲前 3000 字),保证内容与本书相关;应用时只写设定,绝不碰你的大纲,预览页也会标注"仅供参考"。

5左侧 · 🛡 一致性哨兵

把当前章节与角色设定做数值比对:出场次数、年龄、境界等与设定是否矛盾。规则:

  • 必须有可查内容:当前打开了章节,或正文区有文字。两者皆无时按钮禁用,悬停有提示。
  • 检查历史保留在面板里,可回看每次结果。
  • 它查的是数值型矛盾;文风、逻辑类问题用右侧「AI 编剧 → 伏笔检查」预设。

6右侧 · AI 工具六件套

工具做什么目标是什么
✨ 生成正文按大纲梗概写新正文,完整三阶段流水线(草稿→评估循环→润色),带字数保障(不足自动补写)当前章节
✍️ 续写从末尾接着写,500-900 字/次,推进一个情节节拍;同样有字数后检兜底章节末尾(上文窗口 6000 字)
📝 扩写保持原意,补感官/动作/对白/心理,篇幅扩到 2-3 倍选中文字;没选中则处理章节末尾 3000 字(按钮下方常驻提示当前目标)
🔄 重写只改文笔不改情节,句式/用词/节奏,长度 ±20%
🧹 降AI消除 AI 腔(套路排比、"然而/不禁/仿佛"高频词),完成后显示AI 腔密度 前→后对比(每千字模板词命中,变低显示绿色)
📋 生成总纲见 §3,唯一需要填表单的工具整本书

通用机制

  • 上下文参考:扩写/重写/降AI 处理选中文字时,自动携带选区前 ~300 字 + 后 ~100 字作参考(标注禁止输出),模型知道谁在说话、场景在哪。
  • 补充要求:面板里可展开一个文本框,内容追加到任何工具的提示词(例:"主角性格要热血,每章不少于3000字")。
  • 五阶段进度:生成时显示 检索→草稿→润色→评估→安检 的实时进度条。
  • 结果先预览再落笔:生成完先进可编辑草稿区,你可以手改,然后「插入到编辑器」(追加到文末)或「替换选中文字」(仅扩写/重写/降AI 且有选中时出现)。插入/替换前自动存一个版本快照,可回滚。
  • 离开页面生成不中断:后台继续跑,结果保留(最长 10 分钟);回来时会自动取回完整结果。再次点击生成是全新请求,不会"接着断掉的地方写"造成混乱。

7右侧 · AI 编剧

对话式创作助手,带四个预设一键发起:

  • 剧情推演:推演接下来 3 章走向,说明与既有伏笔的呼应;
  • 伏笔检查:查本章与设定的矛盾(性格/世界观/时间线),给修改建议;
  • 章节要点:列 3-5 个写作要点(衔接/推进/伏笔/张力点);
  • 人物打磨:分析出场人物言行是否符合设定与动机。

打开某章时,提问自动携带该章上下文;没打开章节也能用(通用编剧问答)。建议内容可直接「插入到编辑器」。

8顶栏 · 写作设置 / 字数 / 保存 / 索引

  • 写作设置:篇幅(长篇/短篇)× 视角(第一/第三人称)× 频道(男频/女频/全频)。保存进作品元数据,每次生成正文/续写时注入提示词,模型按此行文。
  • 本章字数 / 总字数:本章实时统计(防抖提取,停顿 300ms 刷新);总字数是全部章节之和。
  • 保存:手动 Ctrl+S;有改动时每 30 秒自动保存,按钮显示保存状态("N 秒前保存")。
  • 🧠 记忆库:直达本作品的记忆管理页(见 §10)。
  • 索引徽标:保存后短暂显示「索引中」——后台正在为本章生成检索向量;完成后闪一下「✓已索引」。徽标未消失前,RAG 记忆里还没有这一章的最新内容(通常几秒到几十秒)。

9导出与交稿雷达

中栏右上角「导出」:支持 Markdown / TXT / EPUB。点导出时自动先跑一遍交稿雷达(安全预检),有问题会弹窗列出、可忽略继续(不阻塞导出)。

版本历史:每次保存、每次 AI 插入/替换都会自动存快照;在历史对话框里可对比任意快照与当前内容的差异并回滚。

10记忆库

顶栏「🧠 记忆库」进入(/novels/{id}/memory),一站式查看 AI 能"记住"的全部原料:章节 / 人物 / 世界观 / 剧情事件 / 人物关系 / 知识文档六类,支持搜索和删除。

知识文档是给 AI 喂外部设定的通道:上传 .txt/.md(自动识别 UTF-8 和 GB18030 编码),按 ~800 字分段(段间留重叠防句子被切断)、每段标注「【来源·文件·第N段】」。生成时相关内容会带着出处进入上下文。

12生成机制 FAQ(知其所以然)

AI 写作时"看"得到什么?

检索(5 路并发): 章节相似段 · 角色 · 世界观 · 剧情事件 · 知识文档 → 按相关度合并,设定类加分 → 注入提示词

外加:章节进度、前两章末尾原文(1500 字)、人物关系树、字数目标、写作设置、本卷脉络。检索失败自动降级为直接读库内设定,不会因此写不了。

为什么推荐"生成正文"而不是让 AI 一次写很多?

生成正文走完整流水线:草稿 → 评估打分,不达标自动回炉重润(最多 3 轮) → 字数复查(低于 60% 重写,60-90% 自动补足) → 安全检查。续写走快速链(无评估轮)所以快;重写类只过润色+安检,所以选区操作几乎即时出稿。

检索什么时候能"看到"我刚写的内容?

保存后等「✓已索引」徽标出现。向量是后台生成的,期间 RAG 用的是旧索引;structured fallback(直接读库)则总能看到最新保存的内容。

灵感套件、AI 提取、应用大纲,谁会改我的大纲?

谁都不会。大纲只有三个写入方:你手动编辑保存、AI 润色(确认后)、应用大纲(替换为新的)。灵感套件应用时明确跳过大纲字段——这是设计红线。

写作中途关掉页面会丢稿吗?

编辑内容有 30 秒自动保存 + 关闭前拦截提示;AI 生成结果本地暂存,后台生成继续跑完,回来自动恢复。

一句话工作流:创作向导/手建作品 → 生成总纲(填体裁章数) → 应用大纲自动建章 → 点开第一章 → 写作设置选好篇幅视角 → 「生成正文」起步 → 写顺手后用「续写」推进、「扩写/重写/降AI」打磨 → 交稿前跑交稿雷达 → 导出。
