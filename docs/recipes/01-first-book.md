# 卡片 01｜新书三步开写

> 目标：从“什么都没有”到“写出第一章正文”，最快 3 步。

## 操作步骤

1. **新建作品**
   - 打开前端 `http://localhost:7421`，在作品列表点击“新建”，填写标题与类型（novel / short / script / video）。
   - 系统自动创建作品并获得 `doc_id`（可在作品页地址栏看到）。

2. **配置 LLM（BYOK）**
   - 进入“设置”，填入：API Base（如 `https://api.openai.com/v1`）、API Key、模型名。
   - 点击“测试连接”，确认三个 stage（draft / refine / embedding）均可连通。
   - 若连接失败，见卡片 05（换模型供应商）。

3. **生成并保存正文**
   - 打开作品页，点击“续写”（AI 编剧对话）或直接在章节编辑器里写。
   - 点击“保存”，系统自动分词计数、向量化供后续知识库检索。

## 一行验证

> 刷新作品页 → 能看到标题、正文与管理章节列表；`http://localhost:8000/v1/health` 返回 `{"status":"ok"}`。

## 常见坑

- **保存后看不到章节**：确认后端启动时执行过 `alembic upgrade head`（缺表会 500）。
- **503 / 401**：受保护端点需 `API_KEYS` 已配置且请求带 `X-API-Key`（见 [index.md](index.md) 通用前置）。
- **续写无输出**：检查 BYOK 是否完成三步测试（draft 阶段配置缺失最常见）。
